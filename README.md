# nene_codex_pets

草薙宁宁的 Codex 桌面宠物合集。现有十套造型，各有9种状态动画与16个注视方向。新增「夢をのせたメロディー」特训后新中式礼装 `nene_chinoiserie`（显示名 `宁宁 · 新中式礼装`）。

**[下载十套完整合集 · v1.9.0](https://github.com/scenesuki/nene_codex_pets/https://github.com/scenesuki/nene_codex_pets/releases/download/v1.9.0/nene_codex_pets-v1.9.0.zip)** · [校验和](https://github.com/scenesuki/nene_codex_pets/https://github.com/scenesuki/nene_codex_pets/releases/download/v1.9.0/SHA256SUMS.txt) · [更新记录](https://github.com/scenesuki/nene_codex_pets/releases)

v1.9.0合集包含下列全部十套宠物、完整预览和最终校验记录。选用的制作原素材保留在仓库各套 `source/`。

当前目录、ID和显示名称已按服饰统一，[查看命名对照](PET_NAMES.md)。v1.8.0采用新名称；v1.7.2及更早附件保留原名称。

## 三步安装

1. 下载v1.9.0十套合集，使用同版 `SHA256SUMS.txt` 核对校验和后解压；历史版本按包内说明及[命名对照](PET_NAMES.md)确认旧名称。
2. 将所需宠物目录复制到 `~/.codex/pets/`，确保顶层同时有 `pet.json` 和 `spritesheet.webp`。
3. 打开Codex设置 > Pets，刷新并选择对应中文名称，必要时重启应用。

Windows默认目录为 `%USERPROFILE%\.codex\pets\`；自定义 `CODEX_HOME` 时使用其下的 `pets/`。本次发布不迁移或切换已安装副本；更名前的安装与发布记录继续作为历史凭据。

<details>
<summary>项目结构与全量打包</summary>

每套宠物在根目录独立存放，顶层为当前导入文件、说明与校验；`preview/`保留正式预览、应用规格依据和最终验收。各套 `source/` 保留选用的原始生成图、有效参考图、实际输入和提示词，并提供 `materials-index.json` 索引。参考来源与创作补全写在各套README。共用打包、验证脚本在`scripts/`；本地发布资源在`release-assets/<tag>/`，不提交Git。

从项目根目录运行，`vX.Y.Z`替换为尚未存在的新版本：

```powershell
python scripts/build_release.py --tag vX.Y.Z
python scripts/verify_release.py release-assets/vX.Y.Z/nene_codex_pets-vX.Y.Z.zip
```

脚本自动清点根目录全部`*/pet.json`，核对成品、全部GIF与ZIP文件一致性；缺少资源时停止，已有版本不会覆盖。发布时上传合集ZIP及同目录的`SHA256SUMS.txt`，核对下载哈希。工作区保留最终成果及有效制作原素材；废案、重复缓存和本地历史包按用户授权清理。

工作约定见[AGENTS.md](AGENTS.md)，机器人预览索引见[preview/README.md](nene_robo/preview/README.md)。本地发布目录索引位于`release-assets/README.md`。辅助验证脚本依赖对应Windows应用安装包；预览与打包使用Python及Pillow。
