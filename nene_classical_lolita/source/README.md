# nene_classical_lolita · 制作原素材

- [素材索引](materials-index.json)记录选用原始生成结果、实际输入、有效提示词、来源及SHA-256。
- `decoded/`保存选用的完整原始生成图；`references/`保留卡面、服装核对图和实际生成输入；`prompts/`为制作提示词。
- `frames/`、`final/`、`qa/`为本套分格、组装和检查记录；安装使用宠物目录顶层两个导入文件。
- 生成清单里的外部缓存路径为历史来源，选用原图已逐字节保存在本套目录内。
- 基准图与各状态通过内置imagegen生成；分格、对齐与一次边缘处理由确定性脚本完成。跳跃仅作0/1/2/1/0px整帧垂直定位，未重绘或扭曲人物。

完整造型、规格、已知限制与来源见[本套说明](../README.md)。

本次仅迁移外层目录与素材索引路径；生成清单、提示词、原始验收及制作脚本保留制作时的名称和字节。当前路径以素材索引为准，名称对应见[命名对照](../../PET_NAMES.md)。
